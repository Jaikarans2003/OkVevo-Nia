# ADR-001 — OkVevo is a Hermes Agent fork with owned plugins

Date: 2026-10-22

## Context

OkVevo ships a desktop agent. Forking Hermes and editing `agent/` for brand
and billing made every upstream sync a conflict storm.

## Decision

The Python agent stays byte-identical to Hermes tag **v0.22.4**. Product
behavior lives in OkVevo-owned plugins and `apps/desktop`. Identity is a
generated `SOUL.md` (identity phrases only). KEEP-PATCH cap is 3; current
count is 0.

## Reversibility

Two-way for plugins. One-way for `appId` `com.okvevo.app` once customers
install (OS treats it as a new app).

## Revisit

Next upstream tag merge, or if a required behavior has no extension point
and would need KEEP-PATCH #1.
